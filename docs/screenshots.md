Store only real screenshots captured from the running project.

The items below are future evidence ideas, not evidence that those components are deployed. No AWS infrastructure, Kubernetes cluster, Helm release, Prometheus/Grafana stack, or Calico installation has been verified for this project. Do not run deployment commands merely to create screenshots. The local evidence index records the existing external screenshots, their visible content, and their limitations. Preserve the five protected portfolio images; do not overwrite, edit, or add them to the repository without a separate review.
